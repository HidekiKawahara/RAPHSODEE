1. 概要：音声研究・音響実験における意義

音声コーパスの収録、マイクロホンアレイの評価、あるいは聴覚実験を行う際、事前に収録室や再生・収音系の音響特性を把握しておくことは極めて重要です。スピーカの非線形歪み、空調による低域暗騒音、机面からの初期反射、過剰な残響、あるいはOS標準の意図しない音声フィルタリングが存在すると、基本周波数（f0）推定やスペクトル包絡分析、音声了解度評価の信頼性が大きく損なわれます。

Acoustic Checker by Giant-FFT (Web Edition)（河原英紀 開発、MITライセンス）は、外部ライブラリやWebサーバを一切必要とせず、単一のHTMLファイル（ローカルの file:// 直開きを含む）としてWebブラウザ上で動作する音響チェッカです。周期 N の巡回型試験信号（Cyclic data）を連続再生しながら同時収音し、任意長高速フーリエ変換（Giant-FFT）を100 ms周期で適用することで、以下の音響情報をリアルタイムに分離・可視化します。

  • 線形時不変（LTI: Linear Time-Invariant）伝達特性： スピーカ・室内・マイクロホン系本来の線形周波数応答およびインパルス応答。
  • 時変・非線形（RTV: Random Time-Varying）フロア： 試験信号を鳴らしたままの状態で分離される背景雑音、空調等の時間変動成分、および大振幅時の非線形歪み成分。
  • 間接音・後期残響成分（直接音ピーク +15 ms 以降）： 直接音に対する残響エネルギー比（DRR: Direct-to-Reverberant Ratio）を帯域別に評価するための指標。
  • 帯域別パワー応答（残響減衰曲線）： 任意の周波数帯域における1オクターブ幅のエネルギー減衰過程（残響時間や不自然な反射の診断）。

3. 計測の手順（ステップ・バイ・ステップ）

本アプリケーションはステートマシン（状態遷移）方式を採用しており、左上の System Status に表示される指示に沿って順番に設定を進めます。

  1. 作業フォルダの設定（中央パネル Set working folder）：
    起動後、最初に中央パネル一番上の Set working folder をクリックします。Google Chrome や Microsoft Edge ではフォルダ選択ダイアログが開き、指定したフォルダ内にタイムスタンプ付きのサブフォルダ acTestYYYYMMDDHHMMSS が自動生成され、以降の計測データや画像がダイアログなしで直接保存されます（Safari / Firefox 等の非対応環境では通常のブラウザダウンロードに自動フォールバックします）。直後にマイク権限の許可が求められますので許可してください。
  2. 入出力オーディオデバイスの選択（左パネル）：
    Input / Output device selection の下に2つのドロップダウンが現れます。上段が入力デバイス（マイクロホン／オーディオIF）、下段が出力デバイス（スピーカ／オーディオIF、Chrome/Edge対応）です。
    操作順序の重要ポイント： 出力先を変更したい場合は、必ず先に下段の出力デバイスを選択し、その後に上段の入力デバイスを選択してください。上段の入力デバイスを選択した瞬間に両ドロップダウンが確定（ロック）され、次のサンプリング周波数設定へ進みます。
  3. サンプリング周波数の選択（Sampling frequency）：
    8000〜96000 Hz（通常の音声・室内音響計測では 48000 Hz）を選択します。なお、手順5で周期信号ファイルを読み込むと、ファイル自身のサンプリング周波数に自動更新されます。
  4. 入力チャネル数の選択（Input Channels）：
    1（または 2）を選択します。これにより周期データの読み込み、スペクトル表示モード、および5秒音声メモ機能が有効化されます（本Web版のリアルタイム解析対象は Ch-1［先頭チャネル］です）。
  5. 巡回型試験信号の読み込み（Load cyclic data）と出力チャネル設定：
    Load cyclic data をクリックし、非圧縮の .wav, .aif, .aiff 形式の周期試験信号ファイル（直交周期系列、周期ベルベットノイズ、TSP信号など。インパルス応答窓長1秒を確保するため周期長 N≥3fs の信号を推奨）を選択します。あわせて Output channel（L, R, L and R）で再生チャネルを指定します。
  6. リアルタイム計測の実行（START → 観察 → STOP）：
    START を押すと周期信号の連続ループ再生（最大300秒）と同時収音が開始されます。ブラウザ標準のエコーキャンセラ・ノイズ抑制・自動ゲイン制御はすべて無効化された状態で収音され、1周期分（N サンプル）のデータが蓄積された時点から100 msごとに3つのグラフが更新されます。
    • Spectrum display で Raw DFT（生DFT）、1/3 octave smoothed、1/12 octave smoothed を切り替えられます。
    • BPF fc スライダを動かすと緑色の縦カーソルが移動し、右下グラフの減衰曲線がその周波数帯域にリアルタイム追従します。
    • Snapshot Level を押すと、その瞬間のBand SPL曲線が緑色ラインとして固定表示され、マイク位置や吸音材有無によるA/B比較が行えます。
    確認が終わったら STOP を押します。開始直後1周期分および全区間の再生・収音波形（計4ファイル、24-bit WAV）が自動保存され、初回停止後に中央パネルの Calibrate ボタンが有効になります。

4. 絶対音圧レベル（SPL）校正と音声メモ

4.1 Ch-1 音圧レベル校正（Calibration Ch-1）

未校正の状態では、左下 Band SPL の縦軸はデジタルフルスケール基準の相対値 SPL CAL.NO (dB)（-110〜0 dB）を表示しています。一度以上 START → STOP を実行すると、騒音計（サウンドレベルメータ）を用いた物理音圧レベル（dB SPL re 20 μPa）への校正が可能になります。

  1. 校正済みの普通騒音計（または精密騒音計）のマイク部を計測用Ch-1マイクの直近に並べて設置します。騒音計の周波数重み付け特性はZ特性（平坦 / Flat）またはC特性、時間重み付けは Slow に設定します（校正信号の中心が 1 kHz のため特性間の差は小さいですが、Z特性が基本です）。
  2. 中央パネルの Calibrate をクリックします。1 kHz を中心とする1オクターブ帯域幅（707 Hz〜1414 Hz、1 Hz間隔のランダム位相マルチサイン波、実効値振幅 0.1 すなわち -20 dBFS）が連続再生され、緑色の Recording ランプが点灯します。
  3. 音場と騒音計の指示値が安定するまで 3.1秒以上 待つと、Measured SPL ドロップダウンが自動的に選択可能になります。
  4. 騒音計の読み取り値（95〜65 dB の整数値）を Measured SPL ドロップダウンから選択します。
  5. 選択と同時に再生が停止し、直近3秒間の収音信号の標本標準偏差 σy からデジタル実効値レベル Lobs=20log10(σy) が計算され、校正オフセット値 CdB=LSLM-Lobs が CAL. Value: dB に記録されます。以降、Band SPL の縦軸が絶対音圧 CAL. SPL (dB)（0〜100 dB）に切り替わります。

4.2 実験条件の口頭記録（Voice memo 5s）

収録実験では「どのファイルがどのマイク距離・プリアンプ設定だったか」の記録漏れが頻繁に起こります。ストリーム停止中に Voice memo 5s を押すと、5秒間の音声メモが収音され、最大振幅 0.5（-6 dBFS）にピーク正規化された上で voiceMemoYYYYMMDDHHMMSSr.wav として同一作業フォルダ内に保存されます。

5. 3つのリアルタイムグラフの読み解き方

5.1 上段プロット：伝達関数スペクトル（LTI 対 RTV）

横軸は対数周波数（20 Hz〜fs/2）、縦軸は相対レベル（-80〜+20 dB）です。

  • 青線（LTI） 線形時不変（LTI）伝達特性： 周期インパルス応答の先頭区間から求めた周波数応答です。定在波による鋭いディップやピークを見るには Raw DFT、スピーカや部屋の巨視的な周波数バランスを見るには 1/3 または 1/12 octave smoothed を使用します。
  • オレンジ線（RTV） 時変・非線形歪み・背景雑音フロア（RTV）： 周期インパルス応答の半周期シフト位置（N/2）から抽出した誤差スペクトルです。高精度な音声収録・音響計測には、音声帯域（100 Hz〜16 kHz）全域で青線がオレンジ線より 30〜45 dB 以上高く保たれていることが目安となります。低域で差が縮まる場合は空調・振動騒音、再生音量を上げた際に差が縮まる場合はスピーカやマイクアンプの非線形歪み（飽和）を疑います。
  • 緑色の縦線 BPF fc カーソル： 下部スライダで選択中の中心周波数を示します。

5.2 左下プロット：Band SPL（1オクターブ帯域音圧レベル分解）

1/24 オクターブ間隔の各中心周波数 fc まわりにおける1オクターブ帯域（[fc2-1/2,fc2+1/2]）のエネルギー積算レベルを表示します。

  • 青線（Signal） 観測信号のオクターブ帯域SPL： 収音信号全体の帯域音圧レベルです。
  • 黄線（Indirect / 間接音） 間接音・残響成分レベル（直接音ピーク +15 ms 以降）： 直接音到来時刻から 15 ms 以降に到来する反射・残響エネルギーの換算帯域レベルです。青線と黄線のレベル差が直接音対残響音比（DRR）に対応します。防音ブースや接話収録では黄線が青線より十分に低くなりますが、一般居室でマイク距離が離れると黄線が青線に接近し、残響支配の音場であることが一目で分かります。
  • オレンジ線（Distortion / Noise） RTV（雑音・歪み）換算帯域SPL： 各オクターブ帯域における実効雑音・歪みフロアです。青線との差が帯域別実効SNRになります。
  • 緑線（Snapshot） Snapshot Level 基準線： Snapshot Level ボタン押下時に保持された比較用基準カーブです。

5.3 右下プロット：Power response（帯域別パワー減衰特性）

横軸は時間（0〜1.0 s）、縦軸はピーク値を 0 dB とした正規化パワーレベル（-70〜0 dB）です。

  • 青線（1 kHz 基準） 1 kHz オクターブ帯域パワー減衰曲線： 常に固定表示される 1000 Hz 中心の減衰特性です。
  • 緑線（選択 fc 帯域） BPF fc オクターブ帯域パワー減衰曲線： スライダで選んだ fc を中心に、1/24 オクターブ間隔で配置された前後23チャネル（±11/24 オクターブ範囲）の定Qガウスフィルタ出力パワーを合成した時間包絡です。壁やガラス窓からの孤立エコー（減衰途中の鋭い突起）や、低域での残響時間の伸び、暗騒音フロアへの漸近の様子を周波数別に詳しく確認できます。

6. 信号処理の理論的背景（Giant-FFT と定QガウスBPF）

6.1 Bluestein の Chirp-Z アルゴリズムによる任意長 Giant-FFT

一般的なリアルタイムFFTアナライザは 4096 点などの短い 2m 点フレームに窓関数を掛けて分析するため、窓関数によるスペクトル漏れ（リーケージ）が生じ、長い残響や N=48000 点・144000 点といった任意の整数秒周期信号を正確に1フレームで扱うことができません。本アプリの fftGeneral() は、N が2のべき乗のときは基数2の Cooley–Tukey 法を用い、任意の自然数 N に対しては Bluestein の Chirp-Z 変換を用いて M=2⌈log2(2N-1)⌉ 点の高速畳み込みへと帰着させます。

X[k] = ∑n=0N-1 x[n] e-j2πNnk = b*[k] ∑n=0N-1 (x[n]b*[n]) b[k-n] , b[k] = ejπN(k2mod2N)

チャープ系列 b[k] とその M 点FFTは bluesteinCache にキャッシュされるため、周期長 N に一切制約を設けることなく、窓関数なしの厳密な周期デコンボリューションを100 ms周期で実行できます。

6.2 周波数領域デコンボリューションと時間窓による成分分離

直近1周期分の参照信号 x[n] と収音信号 y[n]（長さ N）のDFT X[k],Y[k] から、周期インパルス応答 h[n] を次式で算出します。

H[k] = Y[k]X*[k] max(|X[k]|2,10-30) , h[n] = ℜ{IFFTN(H[k])}

インパルス応答解析長を L=min(fs,⌊N/3⌋)、最大振幅時刻（直接音ピーク）を npeak=argmaxn|h[n]| とし、巡回インデックス（modN）により長さ L の3成分を切り出します（0≤i<L）。

hLTI[i]=h[i] , hIND[i]=h[(i+npeak+⌊0.015fs+0.5⌋)modN] , hRTV[i]=h[(i+⌊N/2⌋)modN]

半周期シフト位置 ⌊N/2⌋ では室内線形インパルス応答が十分に減衰している（あるいは対称構造を持つ試験信号により線形応答が相殺される）ため、hRTV には系の時間変動（RTV）・非線形歪み・背景雑音のみが抽出されます。

6.3 定Q対数周波数ガウス型帯域通過フィルタバンク

MATLAB版 constantQgaussBPFweight.m を忠実に移植したフィルタバンクであり、最低中心周波数 flow=1000×2-6=15.625 Hz からナイキスト周波数まで 1/24 オクターブ間隔で配置された対数周波数軸上のガウス重みを用います。

Wm(f) ∝ exp(-(log2f-log2fc,m)22σoct2) , σoct = Boct2⋅(2Φ-1(0.75)) ≈ Boct2×1.34898

急峻な矩形フィルタと異なり時間領域でのリンギングを生じないため、振幅重み Wm(f) を用いた逆FFT合成により滑らかで物理的解釈の容易な残響パワー減衰曲線が得られます。

7. 自動保存されるファイルと再現性の確保

すべての録音データはダイナミックレンジ約 144 dB を有する非圧縮 24-bit リニアPCM WAV形式でエンコードされ、作業フォルダ acTestYYYYMMDDHHMMSS/ 内に保存されます（<TS> は保存時刻 YYYYMMDDHHMMSS）。MATLAB や Python を用いた事後の精密オフライン解析にそのまま利用可能です。

8. 正確な計測のための注意点・トラブルシューティング

  • OSレベルの音声処理（ノイズ抑制・声の分離）の無効化【最重要】： 本アプリはブラウザ（WebRTC）に対して echoCancellation: false, noiseSuppression: false, autoGainControl: false を明示的に指定していますが、近年のOSはブラウザの下層で独自の音声強調処理をかける場合があります。必ず以下を確認してください。
    • macOS の場合： 収音中にメニューバー右上のオレンジ色のマイクアイコン（コントロールセンター）を開き、マイクモードが「標準（Standard）」になっていることを確認してください（「声を分離（Voice Isolation）」になっていると試験信号が雑音とみなされ強く抑圧されます）。
    • Windows 11 の場合： 「設定 → システム → サウンド」から使用する録音・再生デバイスのプロパティを開き、「オーディオの強化（Audio Enhancements）」をオフに設定してください。
  • 推奨ブラウザ（Google Chrome / Microsoft Edge）： デスクトップ版の Chrome または Edge の使用を強く推奨します。File System Access API（showDirectoryPicker）により STOP 時の4ファイル一括保存がバックグラウンドで完結するほか、setSinkId() による出力オーディオIFの個別指定にも対応しています。
  • ローカルファイル（file://）からの直接起動： HTMLファイルをダブルクリックしてローカル環境から直接開いても動作します。file:// オリジン制約により AudioWorklet がブロックされる環境では、自動的に同等の全二重 ScriptProcessorNode エンジンへフォールバックする設計になっています。
  • 過大入力と非線形歪みの見分け方： 初回再生時はオーディオIFやアンプの音量を絞った状態から START し、徐々に音量を上げてください。再生音量を上げたとき、上段プロットの青線（LTI）だけでなくオレンジ線（RTV）も一緒に上昇し始める場合は、スピーカの限界またはマイクプリアンプのクリッピング（非線形歪み）が発生しています。
