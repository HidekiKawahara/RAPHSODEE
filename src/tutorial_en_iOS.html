1. Overview & Motivation in Speech Research

Before recording a speech corpus, evaluating microphone arrays, or conducting listening tests, researchers must verify the electro-acoustic signal chain and room acoustics. Subtle issues—such as loudspeaker harmonic distortion, air-conditioning rumble, early desk reflections, excessive reverberation, or unintended OS-level audio filtering—can silently degrade fundamental frequency (f0) estimation, spectral envelope analysis, and speech intelligibility metrics.

Acoustic Checker by Giant-FFT (Web Edition) (developed by Hideki Kawahara, MIT License) runs entirely inside a standard web browser with zero external dependencies—even directly from a local file:// path. By outputting a periodic (cyclic) excitation signal and applying a full-period arbitrary-length Fast Fourier Transform ("Giant-FFT"), the tool decomposes the acoustic path every 100 ms into:

  • LTI (Linear Time-Invariant) Impulse & Frequency Response: The clean linear transfer function of the loudspeaker–room–microphone system.
  • RTV (Random Time-Varying) & Non-Linear Floor: Ambient background noise, time-varying fluctuations (e.g., ventilation fans, clock drift), and non-linear distortion isolated without stopping the excitation.
  • Indirect / Reverberant Energy (+15 ms): Late reflections separated from the direct sound to quantify the Direct-to-Reverberant Ratio (DRR) across frequency bands.
  • Frequency-Selective Power Decay: Octave-band temporal decay curves for inspecting reverberation characteristics (T60 / early decay) interactively across frequency.

3. Step-by-Step Measurement Workflow

To prevent misconfiguration during laboratory sessions, the application enforces a strict sequential state machine: controls remain disabled until prerequisite steps are completed. Follow the System Status indicator in the top-left corner at each stage.

  1. Initialize Workspace (Set working folder — Center Panel):
    Click Set working folder first. In Chromium-based browsers (Google Chrome, Microsoft Edge), select a base directory and grant read/write permission; the app automatically creates a timestamped subdirectory named acTestYYYYMMDDHHMMSS where all recordings and snapshots are saved silently. (In Safari or Firefox, files automatically fall back to standard browser downloads.) The browser will then request microphone access to enumerate audio hardware.
  2. Select Output & Input Audio Devices (Left Panel):
    Two dropdowns appear under Input / Output device selection: the upper dropdown selects the Input (microphone/interface), and the lower dropdown selects the Output (loudspeaker/interface, Chrome/Edge).
    Important Order of Operations: Select your desired Output device (lower dropdown) first, and select your Input device (upper dropdown) second. Selecting an Input device immediately locks both hardware dropdowns and advances to sampling frequency selection.
  3. Select Sampling Frequency (Sampling frequency):
    Choose an initial sampling rate from 8000 up to 96000 Hz (typically 48000 Hz for speech and room acoustics). Note that when you load a cyclic audio file in Step 5, the engine automatically updates its operating sampling rate to match the file's native sample rate.
  4. Select Input Channels (Input Channels):
    Select 1 (or 2) from the dropdown. Setting a non-zero channel count unlocks cyclic file loading, spectrum smoothing modes, and the 5-second voice memo recorder. Note that real-time acoustic analysis processes Channel 1 (input index 0).
  5. Load Cyclic Excitation Signal (Load cyclic data) & Choose Output Routing:
    Click Load cyclic data and choose an uncompressed .wav, .aif, or .aiff periodic test signal (e.g., orthogonal periodic sequence, periodic velvet noise, or TSP/swept-sine with period N, ideally N≥3fs so the 1-second impulse window fits within N/3). Select output routing under Output channel (L, R, or L and R).
  6. Run Full-Duplex Measurement (START → Inspect → STOP):
    Click START. The excitation signal loops seamlessly (up to a maximum safety duration of 300 seconds) while Web Audio captures microphone input with browser AGC, noise suppression, and echo cancellation disabled. Every 100 ms, once at least one full period N has been buffered, all three plots update in real time:
    • Toggle Spectrum display between Raw DFT, 1/3 octave smoothed, and 1/12 octave smoothed.
    • Drag the BPF fc slider to sweep the green cursor across frequencies and inspect band-specific reverberation decay.
    • Click Snapshot Level below the Band SPL plot to freeze the current signal spectrum in green for A/B comparison (e.g., comparing loudspeaker angles or acoustic treatment).
    Click STOP to end streaming. Four 24-bit WAV files (initial cycle and full session, both source and captured) are automatically written to your workspace, and the Calibrate button unlocks.

4. Absolute SPL Calibration & Voice Memos

4.1 Calibrating Channel 1 (Calibration Ch-1)

Prior to calibration, the Band SPL plot displays relative digital levels labeled SPL CAL.NO (dB) (-110 to 0 dB). After completing at least one measurement cycle (START then STOP), you can calibrate the system to physical Sound Pressure Level (dB SPL re 20 μPa):

  1. Position an external calibrated Sound Level Meter (SLM) immediately adjacent to the Ch-1 measurement microphone, facing the loudspeaker. Set the SLM to Z-weighting (Flat) or C-weighting, Slow time weighting (since the calibration signal is centered at 1 kHz, A-, C-, and Z-weightings agree closely, though Z/Flat is standard).
  2. Click Calibrate in the Center Panel. The application synthesizes and loops a 1-octave band-limited multi-sine signal centered at 1 kHz (707 Hz to 1414 Hz at 1 Hz spacing with randomized phases, normalized to an RMS amplitude of 0.1, i.e., -20 dBFS). The green Recording lamp illuminates.
  3. Wait at least 3.1 seconds for the room sound field and SLM reading to stabilize; the Measured SPL dropdown will automatically unlock.
  4. Select the integer SPL value read from your Sound Level Meter (95 down to 65 dB) in the Measured SPL dropdown.
  5. Playback stops automatically. Using the final 3 seconds of recorded audio, the engine computes the sample standard deviation σy, determines the digital RMS level Lobs=20log10(σy), stores the calibration offset CdB=LSLM-Lobs in CAL. Value: dB, and rescales the Band SPL axis to CAL. SPL (dB) (0 to 100 dB).

4.2 Recording Spoken Experimental Logs (Voice memo 5s)

In acoustic field work, paper notes often get separated from audio files. Clicking Voice memo 5s (available whenever the main stream is stopped) records 5 seconds of speech from the microphone—ideal for stating microphone model, talker-to-mic distance, preamp gain, and room condition—normalizes peak amplitude to 0.5 (-6 dBFS), and saves voiceMemoYYYYMMDDHHMMSSr.wav directly into the active session folder.

5. Interpreting the Three Real-Time Plots

5.1 Top Plot: Transfer Function & RTV Floor

Displays relative gain (-80 to +20 dB) across a logarithmic frequency axis (20 Hz to fs/2):

  • Blue Curve (LTI) Linear Time-Invariant Gain: Power spectrum of the primary periodic impulse response segment. Use Raw DFT to spot narrow room modes or standing waves, and 1/3 or 1/12 octave smoothed to inspect overall loudspeaker–microphone timbre balance.
  • Orange Curve (RTV) Random Time-Varying / Distortion Floor: Power spectrum evaluated at a half-period lag (N/2) of the periodic impulse response. For high-quality speech recordings, verify that the Blue LTI curve remains at least 30–45 dB above the Orange RTV curve across the speech band (100 Hz – 16 kHz). If the gap narrows at low frequencies, check HVAC noise; if it narrows at high playback levels, loudspeaker or preamp non-linearity (clipping/harmonic distortion) is occurring.
  • Green Vertical Line BPF fc Marker: Indicates the active center frequency controlled by the slider below the plot.

5.2 Bottom-Left Plot: Band SPL (1-Octave Band Decomposition)

Evaluates integrated 1-octave band levels ([fc2-1/2,fc2+1/2]) at 1/24-octave center spacing:

  • Blue Curve (Signal) Total Octave-Band SPL: Observed band sound pressure level of the received signal.
  • Yellow Curve (Indirect / Reverberant) Late Reverberant Component (+15 ms): Band level of impulse response energy arriving more than 15 ms after the direct-path peak. Comparing the Blue curve to the Yellow curve gives an immediate visual measure of the Direct-to-Reverberant Ratio (DRR). In a dry vocal booth or close-mic setup, the Yellow curve should sit well below the Blue curve; if the Yellow curve approaches the Blue curve, room reflections dominate the microphone signal.
  • Orange Curve (Distortion / Noise) Effective RTV Band SPL: Equivalent band SPL of background noise and time-varying/non-linear components.
  • Green Curve (Snapshot) Reference Level Snapshot: Stored trace captured when pressing Snapshot Level.

5.3 Bottom-Right Plot: Power Response (Temporal Decay)

Displays peak-normalized temporal power decay (-70 to 0 dB) over 0 to 1.0 s (or fftl/fs):

  • Blue Curve (1 kHz Ref) 1 kHz Octave-Band Power Decay: Fixed reference decay curve centered at 1000 Hz.
  • Green Curve (Slider fc) Selected fc Octave-Band Power Decay: Temporal envelope computed from 23 adjacent 1/12-octave filters spanning ±11/24 octaves around fc. Sweep the slider to detect discrete slap-back echoes (sharp secondary spikes) or frequency-dependent reverberation tails (e.g., longer low-frequency decay in untreated rooms) and note where the decay hits the flat horizontal noise floor.

6. Signal Processing Theory (Under the Hood)

6.1 Arbitrary-Length "Giant-FFT" via Chirp-Z (Bluestein's Algorithm)

Conventional real-time analyzers apply short windowed power-of-two FFTs (e.g., 4096 points), introducing windowing leakage and failing to resolve long reverberation tails or exact integer-second periods (such as N=48000 or 144000 samples). When N is a power of two, fftGeneral() executes an in-place Radix-2 Cooley–Tukey FFT. For any arbitrary period length N, it invokes Bluestein's Chirp-Z identity, rewriting the N-point DFT as a linear convolution evaluated via padded Radix-2 FFTs of size M=2⌈log2(2N-1)⌉:

X[k] = ∑n=0N-1 x[n] e-j2πNnk = b*[k] ∑n=0N-1 (x[n]b*[n]) b[k-n] , b[k] = ejπN(k2mod2N)

Because the chirp factors b[k] and their forward M-point FFT are memoized in bluesteinCache, exact leakage-free periodic deconvolution runs effortlessly every 100 ms in JavaScript.

6.2 Periodic Deconvolution & Component Partitioning

Given one full cycle of the reference output x[n] and captured microphone signal y[n] (0≤n<N), the periodic impulse response h[n] is recovered via regularized frequency-domain division:

H[k] = Y[k]X*[k] max(|X[k]|2,10-30) , h[n] = ℜ{IFFTN(H[k])}

Let L=min(fs,⌊N/3⌋) denote the analysis window length and npeak=argmaxn|h[n]| denote the direct-sound arrival index. Three length-L segments are extracted modulo N (0≤i<L):

hLTI[i]=h[i] , hIND[i]=h[(i+npeak+⌊0.015fs+0.5⌋)modN] , hRTV[i]=h[(i+⌊N/2⌋)modN]

When N/2 exceeds the room's reverberation time (or when specially structured cyclic signals cancel linear terms at half-period), hRTV contains zero linear impulse energy and directly measures random time-varying perturbations, non-linearities, and background noise.

6.3 Constant-Q Log-Frequency Gaussian Filterbank

Ported from Hideki Kawahara's constantQgaussBPFweight.m, smoothed spectra and sub-band envelopes use Gaussian weights on a base-2 logarithmic frequency axis starting at flow=1000×2-6=15.625 Hz in 1/24-octave steps:

Wm(f) ∝ exp(-(log2f-log2fc,m)22σoct2) , σoct = Boct2⋅(2Φ-1(0.75)) ≈ Boct2×1.34898

Being Gaussian in log-frequency avoids Gibbs ringing in both time and frequency domains, making it ideal for evaluating reverberation power decay curves via quadrature synthesis (Wm(f)).

8. Experimental Best Practices & Troubleshooting

  • Disable OS-Level Voice Processing (Critical!): Although the Web Edition explicitly requests echoCancellation: false, noiseSuppression: false, and autoGainControl: false from the browser, modern operating systems apply hidden DSP underneath the browser:
    • macOS: While streaming, open Control Center (orange microphone icon in the menu bar) and ensure Mic Mode is set to Standard (never Voice Isolation).
    • Windows 11: Open Settings → System → Sound → Properties for both input and output devices and set Audio Enhancements to Off.
  • Recommended Browser: Use Google Chrome or Microsoft Edge on desktop. Only Chromium browsers currently support the File System Access API (showDirectoryPicker) to write multiple 24-bit WAV files directly into a session folder without triggering four separate browser download prompts on every STOP, as well as AudioContext.setSinkId() for selecting non-default output interfaces.
  • Running Directly from Local Disk (file://): You do not need a web server. If strict browser policies block AudioWorklet module loading on file:// URLs, the application automatically falls back to a synchronized full-duplex ScriptProcessorNode engine without losing functionality.
  • Preventing Acoustic Overload & Hearing Fatigue: Start with conservative amplifier/interface output gain before clicking START, then raise playback level gradually while watching the gap between the Blue (LTI) and Orange (RTV) curves. If raising playback volume causes the Orange RTV curve to rise alongside the Blue curve instead of staying fixed at the ambient noise floor, your loudspeaker or microphone preamplifier is entering non-linear saturation.
