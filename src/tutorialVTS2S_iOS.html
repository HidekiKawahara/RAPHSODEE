序章・準備

なぜ今、声道断面と極配置を手で触るのか？

現代の音声情報処理では、テキストや音響特徴量をニューラルネットワークに入力すれば、極めて自然な音声波形が出力されます。しかしその一方で、「なぜそのスペクトル包絡になるのか」「声道の物理的制約や声帯振動の位相特性が知覚にどう効いているのか」という因果関係は、巨大な重み行列の奥に隠れてしまいました。

1930年代の Chiba & Kajiyama（千葉・梶山）による声道模型の研究から、1960〜80年代の Kelly-Lochbaum 音響管モデル、線形予測分析（LPC）、板倉・斎藤による PARCOR / LSP（LSF）、そして Fant らの L-F 声帯音源モデルに至る先人たちの知恵は、単なる「過去の遺物」ではありません。これらは音声という物理現象を最小の自由度で記述するための数学的結晶であり、最新のニューラル音声コーデックや微分可能DSP（DDSP）の設計思想にもそのまま息づいています。

初期状態では、声道断面積（左上の青い丸印）がすべて「相対面積 $1$（対数面積 $0$）」の一様音響管（Uniform Tube）になっています。声道の長さが約 $17\text{ cm}$ のとき、一様音響管の共鳴周波数（ホルマント）は $500, 1500, 2500, 3500, 4500\text{ Hz}$ に等間隔で並び、曖昧母音（シュワー $/ \partial /$）のような音が聴こえます。また、再生中には右上のグラフに出力音声の短時間フーリエ変換（STFT）スペクトル（赤線）がアニメーション表示されます。

第1章

声道の形から音へ ― 音響管モデルと声道長スケーリング

人間の声道（声門から唇までの空間）は、断面積が場所によって変化する1本の管としてモデル化できます。左上のグラフ（Vocal Tract Area Pad）は、横軸が唇からの距離 (cm)（左端 $0\text{ cm}$ が唇、右端が声門）、縦軸が相対断面積（対数スケール）を表しています。

✏ 実験1-1：マウスで声道の形を描いて母音を作る
  1. 左上のグラフ内をマウスでドラッグし、自由な曲線（緑色の軌跡）を描いてみましょう。マウスを離すと青い断面列が更新され、右下の3D声道チューブの形と右上の伝達関数ゲイン（青線）が瞬時に変化します。
  2. 母音 /a/（ア）を作る： 唇側（左側 $0\sim 7\text{ cm}$）を広く（面積 $4\sim 8$ 程度）、喉の奥側（右側 $9\sim 15\text{ cm}$）を狭く（面積 $0.5\sim 1$ 程度）描いてみましょう。第1ホルマント（$F_1$）が高く、第2ホルマント（$F_2$）が近づき、「ア」に近い音色になります。
  3. 母音 /i/（イ）を作る： 逆に、前方の硬口蓋付近（左側 $2\sim 6\text{ cm}$）を狭く絞り、奥の咽頭腔（右側 $10\sim 15\text{ cm}$）を広く描くと、$F_1$ が下がり $F_2$ が大きく上昇して「イ」の音色に変化します。
  4. 元に戻したいときは、左上グラフ内の Reset ボタンを押します。
📏 実験1-2：声道長（VTL）を変えて子供の声・巨人の声にする
  1. 左上グラフの $8\text{ cm}$ 付近にある水色の太い縦線（VTLハンドル）にマウスを重ねると、左右矢印カーソルに変わります。
  2. この水色の線を右へドラッグすると声道長（VT length）が短くなり（例：$12\text{ cm}$）、すべてのホルマント周波数が高域へシフトして子どものような声になります。
  3. 逆に左へドラッグすると声道長が長くなり（例：$24\text{ cm}$）、大柄な話者の声になります。中央パネルの Source で Female（$F_0 = 250\text{ Hz}$）と組み合わせると、声の高さ（$F_0$）と声道長（VTL）が独立した物理量であることが体感できます。
理論と歴史を深掘りする：Kelly-Lochbaum 音響管と反射係数

1941年に千葉勉と梶山正登は名著 "The Vowel: Its Nature and Structure" において、声道の断面積関数から母音の音色が決定されることを明らかにしました。その後、1962年にベル研究所の Kelly と Lochbaum は、声道を等しい長さ $\Delta x$ を持つ $N$ 個の円筒セクションの連結として離散化し、ディジタル計算機上で音波の伝播をシミュレートするKelly-Lochbaumモデルを提案しました。

音速を $c = 35000\text{ cm/s}$、標本化周波数を $f_s = 44100\text{ Hz}$ とすると、1サンプル時間に音波が往復するセクション長は次式で定まります：

$$\Delta x = \frac{c}{2 f_s} \approx 0.397\text{ cm}$$

隣接する第 $i$ セクションの断面積 $S_i$ と第 $i+1$ セクションの断面積 $S_{i+1}$ の境界では、音響インピーダンスの不連続により音波の反射が生じます。このときの反射係数（Reflection Coefficient） $k_i$ は次式で与えられます：

$$k_i = \frac{S_{i+1} - S_i}{S_{i+1} + S_i} \quad (-1 < k_i < 1)$$

断面積がすべて等しい一様管ではすべての境界で $k_i = 0$ となり、途中での反射は起きません。一方、声道に狭め（狭窄）を作ると $|k_i|$ が大きくなり、特定の周波数で強い定在波（ホルマント共鳴）が立ち上がります。本ツールの VocalTractModel クラスは、描かれた対数断面積から即座に $k_i$ を算出し、Levinson型のステップアップ再帰によって全極型ディジタルフィルタ $1/A(z)$ の予測係数へと変換しています。

第2章

空間のフーリエ基底で声道を操る ― 調音パラメータの低次元化

$44.1\text{ kHz}$ 駆動の音響管モデルでは、約 $17\text{ cm}$ の声道が四十数個の微小セクションに分割されています。しかし、実際の私たちの舌や顎は、隣り合う数ミリごとの断面をギザギザに独立して動かしているわけではなく、空間的に滑らかな大局的変形を行っています。

画面左下の領域（Fourier Modifier Axis）は、声道の対数断面積を空間周波数の低い正弦波・余弦波（第1〜第3調波＋直流成分の計7基底）の重ね合わせとして操作する仕組みです。

🎚 実験2：7つの基底と拡大スライダで声道を連続変形する
  1. まず左上の Reset を押して一様管に戻し、左下の Show all ボタンを押します。7本の色付き正弦波・余弦波と、それらの合成波形である太い黒線が表示されます。
  2. 一番左端にある青い縦のレール（Magnifier Slider）の十字ノブ（+）を上下にドラッグしてみてください。左上の声道断面積（青線）と緑色のインジケータが連動して大きくうねり、音色が連続的にモーフィングされます。
  3. 次に、左下の Reset を押してすべての基底係数を $0$ にした後、7つの色付き丸印（アンカー）のうち1つだけを上下にドラッグしてみましょう。
  4. 空間の第1周期成分（唇側と喉側で逆相に動く成分）だけを動かしたときと、第2・第3周期成分を動かしたときで、右上の第1・第2・第3ホルマントがそれぞれどのように移動するか観察してみましょう。
理論と歴史を深掘りする：声道断面積の固有モード展開と摂動理論

一様音響管の対数断面積 $\log S(x)$ に対して空間的な微小摂動 $\Delta \log S(x)$ を加えたとき、第 $n$ ホルマント周波数 $F_n$ がどれだけシフトするかは、声道長を $L$ とすると空間の余弦成分 $\cos\left(\frac{(2k-1)\pi x}{L}\right)$ との内積によって一次近似できることが知られています（Schroeder 1967, Mermelstein 1967）。

本ツールでは、唇からの距離 $x \in [0, L]$ に対して以下の7つの空間フーリエ基底 $\phi_m(x)$ を用意しています：

$$\phi_{2k-1}(x) = \sin\left(\frac{k \pi x}{L}\right), \quad \phi_{2k}(x) = \cos\left(\frac{k \pi x}{L}\right) \quad (k = 1, 2, 3), \quad \phi_7(x) = 1$$

これにより、40次元以上の断面ベクトルをわずか数個の係数で滑らかに制御できるだけでなく、さらにその上から自由曲線を描き足すことで「大局的な母音構え＋局所的な子音狭窄」の合成も直感的に行えます。

第3章

スペクトル・極（ホルマント）・LSFの双対性

ここまでは「声道の形 $\rightarrow$ スペクトル（順問題）」を動かしましたが、このツールの真骨頂は「スペクトル上の極（ホルマント）を直接つまんで動かすと、対応する声道の形がリアルタイムに逆算される（逆問題）」点にあります。

右上のグラフ（GainPlot）には、2つの縦軸があります：

  • 左縦軸（青色）： 声道伝達関数のゲイン（dB）と青い実線スペクトル。
  • 右縦軸（オレンジ色）： 伝達関数の極（Pole）の帯域幅（Bandwidth: Hz）。上に行くほど帯域幅が狭く（$1\text{ Hz}$）、鋭い共鳴ピークになります。プロット内のオレンジ色の丸印が各ホルマント極の位置（横軸：周波数、縦軸：帯域幅）を表しています。
🎯 実験3-1：極（オレンジ色の丸）を直接ドラッグして声道を逆算する
  1. まず左上グラフで適当な曲線を描いて、右上のグラフにオレンジ色の丸印（極）を出現させます。
  2. オレンジ色の丸印の上にマウスカーソルを合わせると指マークに変わります。そのままドラッグして左右（周波数の変更）や上下（帯域幅の変更）に動かしてみましょう。
  3. 極を1つ動かすだけで、その伝達関数を実現するために必要な左上グラフの声道断面積全体が瞬時に再計算されて変形する様子を確認してください。
  4. 丸印を上方向（帯域幅 $10\text{ Hz}$ 以下）へ持ち上げると、スペクトルの山が針のように鋭くなり、合成音に「ピー」という強い共鳴音（笛のような鳴り）が混じることを聴いて確かめましょう。
📊 実験3-2：青い破線（LSF: 線スペクトル対）のインターレース性を観察する
  1. 右上のグラフに並んでいる青い縦の破線に注目してください。これはLPC予測多項式から算出された LSF（Line Spectral Frequencies / 線スペクトル対 LSP） です。
  2. スペクトルの山（極）が高い場所では、青い破線が2本〜3本ギュッと密集し、平坦な場所では等間隔に離れていることがわかります。
  3. どんなに極端に声道を描いたり極を動かしたりしても、青い破線同士が交差して順番が入れ替わることは絶対にありません。
理論と歴史を深掘りする：なぜLPC・PARCOR・LSF（LSP）が世界を変えたのか？

1960年代末、板倉文忠と斎藤収三（電電公社武蔵野通研）、および米国の Atal らは、音声のスペクトル包絡を全極型フィルタ $H(z) = 1 / A(z)$ として推定する線形予測分析（LPC）とPARCOR（偏自己相関）係数を確立しました：

$$A(z) = 1 + \sum_{k=1}^{p} a_k z^{-k} = \prod_{k=1}^{p} (1 - z_k z^{-1})$$

極 $z_k = r_k e^{j\theta_k}$ の偏角 $\theta_k$ がホルマント角周波数、絶対値 $r_k = \exp(-\pi B_k / f_s)$ が帯域幅 $B_k$ に対応します。本ツール（JavaScript版）では、次数 $p \approx 44$ の多項式 $A(z)$ のすべての複素根を Aberth-Ehrlich 同時反復法 によってミリ秒単位で求め、逆に極をドラッグした際には根から多項式 $A(z)$ を再構成し、ステップダウン再帰（lpcToReflection）で反射係数 $k_i$（$|k_i| \le 0.995$ に安定化クランプ）へ戻すことで声道断面積 $S_i$ を復元しています。

さらに1975年、板倉によって発明された LSP（Line Spectrum Pairs / LSF） は、声門端を「完全閉鎖」または「完全開放」した境界条件に対応する対称多項式 $P(z)$ と反対称多項式 $Q(z)$ を定義します：

$$P(z) = A(z) + z^{-(p+1)} A(z^{-1}), \qquad Q(z) = A(z) - z^{-(p+1)} A(z^{-1})$$

フィルタ $1/A(z)$ が安定（すべての極が単位円内）であるための必要十分条件は、「$P(z)$ と $Q(z)$ のすべての根が単位円上にあり、かつ交互に並ぶ（インターレースする）こと」です。予測係数 $a_k$ をそのまま量子化したりフレーム間で線形補間したりするとフィルタが容易に発散してしまいますが、LSF領域であれば「昇順に並んでいる限り100%安定」が保証されます。この驚異的な性質により、LSFは携帯電話の標準音声コーデック（AMR, EVRC, SILK, Opus等）から統計的音声合成に至るまで、40年以上にわたり世界中の通信インフラを支え続けています。

第4章

声帯音源のデザインと抗エイリアシング ― L-FモデルとF0軌跡

ソース・フィルタ理論のもう一方の主役が声帯音源（Glottal Source）です。声帯の開閉によって生じる体積流（Volume Velocity: $U_g(t)$）と、唇での放射特性を含めたその時間微分波形（Glottal Flow Derivative: $E_g(t) = dU_g/dt$）の形状が、声の「張り」「息漏れ感（気息性）」「きしみ（ボーカルフライ）」といった声質（Voice Quality）を決定づけます。

🎵 実験4-1：L-Fモデルの4つの時間パラメータを動かして声質をデザインする
  1. 画面最上部のタブバーで 2. L-F Source & F0 Designer タブをクリック（または中央 Source パネルの Voice Quality で Design を選択）します。
  2. 左上が1周期分の声門体積流 $U_g(t)$、左下が微分声門流 $E_g(t)$（L-Fモデル波形）、右上が $+6\text{ dB/oct}$ 強調された音源スペクトル包絡です。
  3. 左下グラフ内の青い縦線（$t_p, t_e, t_c$）と赤い丸印（$t_a$：復帰相の時定数）を左右にドラッグしてみましょう。
  4. 特に赤い丸印（$t_a$）を右へ倒す（$t_a$ を大きくする）と、声門閉鎖時の角が丸まり、右上グラフの高域スペクトルが急激に減衰して息漏れ声（Breathy voice）になります。逆に $t_a$ を左端へ近づけると、閉鎖時点 $t_e$ で鋭い不連続（インパルス状の励振）が生じ、高次倍音まで豊かな張りのある声（Modal / Pressed voice）になります。
  5. 右下の Play Source ボタンを押すと、声道フィルタを通す前の「声帯音源そのままの音」を聴くことができます。
📈 実験4-2：F0軌跡をフリーハンドで描いてイントネーションをつける
  1. 第1タブの Source パネルにある Male ドロップダウンを Design に切り替える（または第2タブ右下の F0 キャンバスを表示する）と、F0軌跡スケッチパッドが有効になります。
  2. 右下の白いグラフ（横軸：時間、縦軸：音名）の上でマウスをドラッグして、自由なピッチ曲線（疑問文のような尻上がりや、抑揚のあるメロディ）を描いてみましょう。
  3. 左端の青い縦スライダで基準F0を上下でき、グラフ中央の緑の縦線を左右にドラッグすると全体の発話時間長（Duration）を伸縮できます。
  4. ← Back to Vocal Tract で第1タブに戻り、Sound it を押すと、あなたがデザインした声質とF0イントネーションで声道が鳴り響きます！
理論と歴史を深掘りする：L-Fモデルの数式と「解析的抗エイリアシング」の仕掛け

1985年に Gunnar Fant, Johan Liljencrants, Qiguang Lin が提案した L-Fモデル（Liljencrants-Fant Model） は、1周期（正規化時間 $0 \le t \le 1$）の微分声門流 $E_g(t)$ を、開放相（Opening Phase: $0 \le t < t_e$）の指数増大正弦波と、復帰相（Return Phase: $t_e \le t \le t_c$）の指数減衰曲線という2つの区間で記述します：

$$E_g(t) = \begin{cases} E_0 e^{\alpha t} \sin(\omega_g t) & (0 \le t < t_e) \\[6pt] -\dfrac{E_e}{\varepsilon t_a} \left[ e^{-\varepsilon (t - t_e)} - e^{-\varepsilon (t_c - t_e)} \right] & (t_e \le t \le t_c) \\[6pt] 0 & (t_c < t \le 1) \end{cases}$$

ここで $\omega_g = \pi / t_p$ であり、減衰率 $\varepsilon$（コード内では betaa）と増大率 $\alpha$（alphaa）は、「1周期にわたる微分の積分値（＝閉鎖時の体積流）が厳密にゼロに戻る」という物理的境界条件 $\int_0^{t_c} E_g(t) dt = 0$ を満たすように非線形方程式（fzero）を解いて決定されます。

【なぜ単純に計算すると音が汚くなるのか？（エイリアシング問題）】
L-Fモデルの波形は $t = t_e$ において導関数が不連続（折れ曲がり）になるため、その周波数スペクトルは無限遠の周波数まで $1/\omega^2$（$-12\text{ dB/oct}$）でしか減衰しません。これを離散時間サンプル点 $t = n / f_s$ でそのまま標本化すると、ナイキスト周波数 $f_s/2$ を超えた高調波成分が折り返すエイリアシング雑音が発生し、特にF0を動かした際に「ジリジリ」という耳障りな非調和ノイズとして知覚されます。

本ツールの LFSourceModel クラスには、河原（2015）による6項コサイン窓（Nuttall型の連続微分窓）を用いた解析的畳み込み積分（Analytical Antialiasing）が実装されています。連続時間領域で区分的な複素指数関数 $e^{\beta t}$ および多項式と、有限長の低域通過コサイン窓 $w(t) = \sum_{k=0}^{5} a_k \cos(k \pi t / t_w)$ の畳み込み積分を数式として厳密に解いた閉形式（Closed-form）で計算した上でサンプル点を評価し、最後に窓関数による高域の緩やかな減衰を最小位相FIR/IIRイコライザ（equalizerDesignAAFX）で補償しています。これにより、オーバーサンプリングを一切行わずに、折り返し雑音のない透き通った声帯音源波形を実時間生成しています。

第5章

自分の声とモデルを重ね合わせる ― リアルタイム・スペクトルモニタ

最後のステップとして、これまで学んだ「声道フィルタ＋L-F声帯音源」による総合スペクトル包絡（緑線）と、今この瞬間にマイクから入力されるあなた自身の声のスペクトル（黒線）を同じグラフ上で重ね合わせて比較してみましょう。

🎤 実験5：自分の母音を観察し、同じ音色を合成してみる
  1. 第1タブ右下の ☑ Monitor チェックボックスをONにすると、Sound Monitor パネルが現れます。
  2. Start ボタンを押してブラウザのマイク使用を許可し、マイクに向かって「アー」や「イー」と持続母音を発声してみましょう。
  3. 右上グラフに黒い実線（60 ms Nuttall窓による 8192点 FFT スペクトル）がリアルタイムに描画されます。良いところで Stop を押すと、その瞬間のスペクトルが画面に固定され、Play ボタンで直近 $200\text{ ms}$ の録音音声を聴き返すことができます。
  4. 固定された黒線のスペクトル包絡のピーク位置（第1・第2・第3ホルマント）と高域への傾き（スペクトルティルト）をよく観察し、極のドラッグや声道描画、VTL調整、L-Fモデル調整を駆使して、青い伝達関数（または緑色の総合スペクトル包絡）をあなたの声のピークに重ね合わせてみましょう！
  5. うまく合成できたら、Save ▾ ボタンから好きなフォルダを選んで 24-bit WAV音声（.wav）・断面積テキスト（.txt）・状態ファイル（.json） を保存してみましょう。
理論と歴史を深掘りする：Analysis-by-Synthesis (AbS) から現代の音声科学へ

今あなたが手動で行った「観測された実音声のスペクトルに最も近くなるように、内部の生成モデルのパラメータを調整する」というアプローチこそが、1960年代に Bell 研や MIT（Stevens & Halle）で提唱された Analysis-by-Synthesis（合成による分析：AbS） そのものです。

現代のニューラル音声合成や自己教師あり学習モデル（WavLM, HuBERT等）を研究する際にも、「フォルマント遷移がなぜその軌跡を描くのか」「声帯閉鎖の急峻さがスペクトル傾斜と知覚的な声の張り・距離感にどう寄与するのか」「どの特徴量が声道長（話者性）に依存し、どの特徴量が音韻に依存するのか」を物理レベルで体感していることは、モデルの挙動を解釈し新しいアーキテクチャを設計する上で強力な羅針盤になります。
